# Runtime Skeletal Mesh to Procedural Mesh Unreal Engine Plugin

<!-- Plugin description -->
Converting a skeletal mesh to a procedural mesh at runtime.
<!-- Plugin description end -->

## Install

1. Download SkeletalToProcedural Unreal Plugin release zip for you Unreal Engine version https://github.com/romaktion/SkeletalToProceduralUnreal/releases/
2. Extract to [Project directory]/Plugins folder

## How to use

You need to just call SkeletalToProcedural passing your SkeletalMeshComponent and ProceduralMeshComponent
